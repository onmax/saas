This template is a ready-to-use SaaS starter made with [Nuxt UI](https://ui.nuxt.com) for building a landing page, pricing, docs, blog, and an authenticated app area.

Authentication is powered by [Better Auth](https://better-auth.com) via [`@onmax/nuxt-better-auth`](https://better-auth.onmax.me). Persistence uses [NuxtHub](https://hub.nuxt.com/) (database + KV), and billing is implemented via [Polar](https://polar.sh/) using Better Auth plugins.

## Key Features

This template includes a range of features designed to streamline documentation management:

- **Powered by** [**Nuxt**](https://nuxt.com): Utilizes the latest Nuxt framework for optimal performance.
- **Built with** [**Nuxt UI**](https://ui.nuxt.com): Integrates a comprehensive suite of UI components.
- [**MDC Syntax**](https://content.nuxt.com/usage/markdown) **via** [**Nuxt Content**](https://content.nuxt.com): Supports Markdown with component integration for dynamic content.
- **Authentication**: Email/password and GitHub OAuth via Better Auth.
- **Billing**: Checkout and customer portal via Polar.
- **Database + KV**: NuxtHub (D1/KV on Cloudflare Workers).
- **Auto-generated Sidebar Navigation**: Automatically generates navigation from content structure.
- **Full-Text Search**: Includes built-in search functionality for content discovery.
- **Optimized Typography**: Features refined typography for enhanced readability.
- **Dark Mode**: Offers dark mode support for user preference.
- **Extensive Functionality**: Explore the template to fully appreciate its capabilities.
