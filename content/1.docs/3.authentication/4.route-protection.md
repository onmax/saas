This starter protects routes using the `auth` integration from `@onmax/nuxt-better-auth`.

You can set auth requirements globally in `nuxt.config.ts` and override them per page with `definePageMeta({ auth: ... })`.

## Auth modes

- `'user'`: requires an authenticated user
- `'guest'`: only unauthenticated users (logged-in users are redirected)
- `{ user: {...} }`: requires the user to match specific properties (for example a role)
- `false`: no protection

## Global protection (route rules)

This starter uses route rules like:

```ts [nuxt.config.ts]
routeRules: {
  '/app/**': { auth: 'user', prerender: false },
  '/login': { auth: 'guest', prerender: false },
  '/signup': { auth: 'guest', prerender: false }
}
```

## Per-page protection

Pages can also declare their auth mode:

```vue [app/pages/app/billing.vue]
<script setup lang="ts">
definePageMeta({ auth: 'user' })
</script>
```

## Redirects

Redirect behavior is configured in `nuxt.config.ts`:

```ts [nuxt.config.ts]
auth: {
  redirects: {
    login: '/login',
    guest: '/app'
  }
}
```
