Better Auth plugins extend the auth server (new routes, hooks, behavior) and often extend the client API (new `client.*` methods).

In this starter, plugins are configured in two places:

- Server plugins in `server/auth.config.ts`
- Client plugins in `app/auth.config.ts`

## Why you need both

If you add a plugin on the server, you typically also add its client counterpart so the client gets the right methods and types.

Example:

- Server plugin: `admin()`
- Client plugin: `adminClient()`

## Plugins enabled in this starter

### Admin plugin

The Better Auth admin plugin enables role-based access control.

- Server: `admin()` in `server/auth.config.ts`
- Client: `adminClient()` in `app/auth.config.ts`

You can use roles in route protection (see [Route protection](/docs/authentication/route-protection)).

### Polar plugin

Billing is wired through the Polar Better Auth plugin:

- Server: `polar(...)` with `checkout(...)`, `portal(...)`, and `webhooks(...)`
- Client: `polarClient()`

This is what makes methods like `client.checkout(...)` and `client.customer.portal()` available in pages like `app/pages/pricing.vue` and `app/pages/app/billing.vue`.
