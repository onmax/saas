Billing in this starter uses [Polar](https://polar.sh/) via Better Auth plugins (`@polar-sh/better-auth`).

## Checkout and portal

The server config (`server/auth.config.ts`) enables:

- `checkout(...)` for starting a checkout flow
- `portal(...)` for opening the customer portal

On the client side (through `polarClient()`), this starter uses:

- `client.checkout({ slug })` in `app/pages/pricing.vue` and `app/pages/app/billing.vue`
- `client.customer.portal()` in `app/pages/app/billing.vue`
- `client.customer.state()` to show subscription state in `app/pages/app/billing.vue`

## Product slugs vs product IDs

This starter starts checkout with a plan slug (`basic`, `standard`, `premium`).

Slug-based checkout depends on these env vars:

- `POLAR_PRODUCT_BASIC_ID`
- `POLAR_PRODUCT_STANDARD_ID`
- `POLAR_PRODUCT_PREMIUM_ID`

## Webhooks

Configure a Polar webhook pointing to:

- `POST /api/auth/polar/webhooks`

Set the webhook secret:

- `POLAR_WEBHOOK_SECRET`

## Environment

- `POLAR_SERVER=production` uses `https://api.polar.sh`
- `POLAR_SERVER=sandbox` uses `https://sandbox-api.polar.sh`
