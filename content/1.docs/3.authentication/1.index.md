This starter uses [Better Auth](https://better-auth.com) via [`@onmax/nuxt-better-auth`](https://better-auth.onmax.me).

Key pieces:

- Nuxt module: `@onmax/nuxt-better-auth` (see [module docs](https://better-auth.onmax.me))
- Better Auth core: see [core docs](https://www.better-auth.com)
- Persistence: [NuxtHub](https://hub.nuxt.com/) (database + KV)
- Billing: [Polar](https://polar.sh/) via Better Auth plugins

## Where things live

- Server config: `server/auth.config.ts`
- Client config: `app/auth.config.ts`
- Module + redirects + route rules: `nuxt.config.ts`

## Environment variables

Start from `.env.example`. At minimum you need:

- `NUXT_PUBLIC_SITE_URL`
- `BETTER_AUTH_SECRET`

If you keep GitHub OAuth, email verification, password reset, and billing enabled, you also need the GitHub, Resend, and Polar variables from `.env.example`.
